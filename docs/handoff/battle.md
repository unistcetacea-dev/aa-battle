# 배틀 진행 (턴·교대·추격·대미지) (PROJECT_HANDOFF.md에서 옮김)

## 계산 규칙

기본 능력치와 대미지는 첨부된 슈퍼 마개조 계산기 Ver 3.617을 기준으로 한다. 낮은 레벨과 레벨 차 1% 보정, 시트의 내림 순서, 85~100 난수, 급소 2배를 유지한다. 일반 상태와 날씨는 현대 싱글 규칙을 참고하되 시트 확장인 동상과 과거 싸라기눈을 별도 지원한다.

현재 회귀 검사에는 원본 시트의 290~342 대미지 및 난수 0.87에서 297, 타입 무효, 날씨·필드, 상태, 대타, 행동 순서, 팀 편집기 종족값 변환이 포함된다.

## 대미지 지연(『전투속행』)
- 표준 문장 「자신은 상대의 기술의 대미지를 (드물게/저확률로/중확률로) 자신의 행동 후로 미룬다.」(`DeferredDamage.cs`, 효과 종류 「대미지 지연」, 「데미지」 표기도 정규화). 확률은 문장 안에서 맞을 때마다 판정한다.
- 대미지 계산 뒤 체력을 깎기 전에 판정하고, 성공하면 체력 감소만 보류한다. 아직 행동하지 않은 상대(행동 예정)에게만 걸리며, 이미 행동했으면 평소대로 즉시 적용한다.
- 보류 대미지는 자신의 행동 직후(행동 루프 앞머리 `FlushActed`), 교대 직전(`SwitchNow`), 행동하지 못한 채 루프가 끝났을 때(`FlushAll`) 적용한다. 여러 번 보류되면 합산한다.
- 추가효과·반동·드레인·접촉 반응·「대미지를 받았을 때」 트리거는 원래 시점에 처리한다. 버팀 판정(`Engine.ReduceByEndure`, `BattleEngine.Endure.cs`)은 실제로 체력이 줄어드는 적용 시점에 한다.
- 후속 결정: 실질적으로 죽을 대미지(버팀 적용 전 원래 대미지가 현재 체력 이상)에만 판정한다. 드레인·반동·`Received/Hit`·트레이너 「대미지를 받았을 때」는 원래 시점에 보류된 양 기준으로 처리하고, 체력 감소만 미룬다. 적용 때 `Damaged`는 다시 내지 않는다.

## 2026-09-16 유턴·효과 교대 실행
- `SwitchRuntime`은 교대 요청을 `턴 중간`과 `턴 마지막`으로 구분한다. 유턴 태그 기술은 기술 처리(명중·대미지·부가효과)가 끝난 직후 다음 행동 전에 교대하고, `아군과 교대` 효과를 가진 포켓몬/트레이너 포텐셜은 해당 트리거 로그가 확정된 사건 처리 직후 교대한다. `T 종료 시` 트리거는 턴 종료 처리 뒤 교대한다.
- `SwitchRequest`를 배틀 창의 모달 선택창에 연결했다. 효과가 성립하면 현재 파티의 살아 있는 대기 포켓몬을 보여 주고, 선택한 포켓몬의 등장·설치물·등장 특성·상대 등장 트리거까지 같은 교대 경로로 처리한다. 취소하면 선택적 교대 효과는 발동하지 않는다.
- `TurnResult.Switches`가 한 턴 안의 여러 교대 기록을 보존하며, UI는 각 기록을 대기 목록과 현재 상태에 반영한다. 유턴 효과를 부여하는 포텐셜과 트레이너 고유 포텐셜도 현재 행동의 유턴 교대로 연결한다.
- 일반 포텐셜 전체 자연어 실행기가 완성된 것은 아니다. 이번 자동 실행 범위는 이미 확정 트리거 로그가 발생한 교대 효과와 유턴 효과이며, 교대 이외의 문장 효과·강제교대·배턴터치의 능력변화 인계는 기존처럼 별도 구현 대상이다.

## 2026-10-12 F4b 추가행동 (확정 29)
- 표준 문장: `「N」배수 T, 가장 먼저/마지막에 「조건」 기술에 의한 추가행동을 얻는다.`(배수·조건 생략 가능, `같은 기술에 의한`). 정규화: 추가행동권·추가 행동·T의 최후에·제일 마지막에·배수의 T·기술 「이름」에 의한·「칼」「검」등의 기술. 「지령에 의한 추가행동권」은 다른 규칙이라 바꾸지 않는다(판정 대기).

- `BenchEvents`는 빈사 아닌 대기 멤버 중 필드 밖 발동·자진 전체 발동·교대 효과만 실제 사건을 관측한다. 아군의 필드 턴 타이밍 조건은 필드 아군을 기준으로 판정하고, 트리거가 만족되면 대기 보유자를 실행 주체로 큐에 올린다.
- 대기석 스토킹/역선회는 해당 효과가 명시한 상대 등장 또는 필드 아군의 두 번째 필드 턴 종료 사건에서 실제 `SwitchNow` 경로로 교대한다. 대기 포텐셜 선행입력은 적격 문구가 있고 살아 있는 보유자에게만 선언된다.
- 대기 로봇은 실제 명중 사건으로 선언 효과를 실행한다. 회복 대상은 자기 팀의 현재 필드 멤버이며, 반납 대미지는 보유자가 대기석으로 이동한 뒤에도 턴 끝에 적용된다.
- 대기석 교대 보정: 대기석에서는 「교대해 필드에 나올 수 있다」 진입형(`BenchEvents.IsEntrySwitch`)과 「필드에 없어도 발동」·「PT 전원」만 판정한다(「아군과 교대할 수 있다」 둔주류는 장소에 있을 때만). 대기석 트리거 로그에 보유자 이름 표지(`BenchTag`)를 붙여 다른 포켓몬의 같은 이름 포텐셜과 섞이지 않게 하고, 처리한 로그 위치(`HandledBenchLines`)는 다시 쓰지 않으며, 교대 전에 `OptionalEffectPrompt`로 먼저 묻는다(거절 시 교대 없음). 라이브러리 스토킹·역선회·텔레포터 효과 문장을 「교대해 필드에 나올 수 있다」로 고쳤다.
- 사용자 결정: 진입형 교대(역선회·스토킹·텔레포터·역윤회 등)는 대기석 전용이다. 필드에 있는 보유자는 스스로 물러나지 않도록 `SwitchEffectRuntime.TriggeredSwitches`가 진입형(`IsEntrySwitch`)을 제외한다. 둔주류(필드에 나온다는 문구 없음)는 필드에서만 작동한다.
- 검사: `BenchEventsTests` (오프필드 사건, 스토킹, 역선회, 로봇 선행입력/반납, 교대 후 반납, 부적격·빈사 선행입력).
