# 샘플 파티(실프 인헨스먼츠) — 모듈로 못 만드는 것

기준: `samples/abaddon-sylph.aabdata.json`을 만들 때 각 트리거·효과 문장을 `TriggerModules`/`EffectModules`(`EffectNormalizer.Normalize`·`ModuleCatalog.TryRead`·`EffectModules.Classify`)로 읽어 본 결과. 읽히지 않는 문장은 저장 파일에 원문 그대로(트리거·효과 칸 + `raw`) 두었고, 실행 때 「효과 판정 대기」가 된다.
표의 「상태」: **없음** = 트리거 또는 효과 문장을 어느 쪽도 못 읽음, **분류만** = 엔진이 종류는 알아보나 편집기 빈칸 채우기 모듈(`TryRead`)은 없음.

## 사용자 결정으로 제외
- 『너를 죽이기위한 작품』(마히토 고유) — 구현이 힘들어 넣지 않음.

## 캐릭터별 개수 (읽히지 않는 포텐셜 수 / 그중 분류만)
마히토 9(분류만 1 포함) · 오버홀 8 · 삼각두 9(분류만 2 포함) · 루나틱 10(분류만 2 포함) · 이리스 7(분류만 1 포함) · 로보코 7(분류만 2 포함). 합계 50개 중 **없음 42 / 분류만 8**(삼각두의 『수렵대원』은 편집기 템플릿의 「필요 통솔」 꼬리표 때문에 분류되지 않을 뿐 템플릿 그대로다). 이 중 `전투속행`·`초근성`·`기합`·`프라이멀 헌트`·`와일드 헌트`는 기존 편집기 템플릿(고정 선택지)이지만 엔진에 실행기가 없는 것이다(「기존 템플릿 미구현」 묶음).
(금관 사이즈·하프는 설정 문장은 버리고 효과 문장만 남겼다. 도살자는 「이 배틀에서는 발동하지 않는다」라 발동 금지로 저장.)

## 표기 차이로 데이터 이름에 맞춰 둔 것 (보고용)
- 기술: 속이다 → 속이기, 스톤엣지 → 스톤에지, 스킬스웹 → 스킬스왑, 탁쳐서떨구기 → 탁쳐서떨구기（1P）(데이터에 1P/2P 동일 내용 두 개).
- 소지품: 바라비열매 → 바리비열매, 기술머신(다른차원홀) → 기술머신(이차원홀)(기술 이름 이차원홀과 같은 기술로 판단). 돌격조끼는 데이터에 없어 시트 이름 그대로.
- 특성: 결벽증은 데이터에 없어 시트 이름 그대로(실행 안 됨).
