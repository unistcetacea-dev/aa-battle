- 공용화: AutoMoveName/AutoAction/AutoActionLabel을 난동과 연속 사용에서 공유한다. ## 2026-10-12 기능확장 · 트레이너 고유의 「아군」
- 기능확장(사용자 정의): 포켓몬 기술 목록(개수 제한 없음, 4개보다 많을 수 있다)에 없는 기술을 내보내는 것. `AABattle.Engine/FunctionExtensions.cs`. 표준 문장 `자신이/아군 전원이 「기능확장:X」(「기능확장:Y」…)을/를 내보낼 수 있다.`(「PT 전원·PT의 아군 전원」 → 아군 전원, 「기능확장 「X」」·「기능확장(X)」·「기능확장 : X」, 「사용할 수 있다」 → 「내보낼 수 있다」, 여러 기술 이어 쓰기).
- 고를 수 있는 기술(`FunctionExtensions.Available`): 자신의 포텐셜(조건이 지금 성립) + PT의 다른 멤버의 「아군 전원」(빈사여도, 오레마스 시스템 「아군이 PT에 참가하고 있을 때」) + 트레이너 고유 + 사건으로 얻은 것(`ConditionState.ExtensionMoves`, 장소를 떠날 때까지). 자기 기술 목록에 있는 것은 뺀다.
- 배틀 화면에 「기능확장」 버튼(선택·해제). 고르면 `BattleCommand.Extension`, 엔진은 그 행동의 기술 사본에 `Move.extension`을 켠다. 기술 조건 「기능확장」(`MoveCondition`)이 이 표시를 보므로 「자신이 「기능확장」을 내보낼 때」, 「자신의 「기능확장」 기술의 위력을 강화」, 「「기능확장」에 「물」타입을 추가해 유리한 상성」 같은 트리거·효과가 그대로 작동한다(예전에는 「기능확장」을 기술 태그로 읽어 절대 맞지 않았다). 「구애」는 아직 엔진에 없다(문서: 기능확장 기술은 구애되지 않고, 구애 중이면 기능확장 불가). 「1시합 1회」 같은 사용 제한은 아직 소비하지 않는다.
- 트레이너 고유의 「아군」 = 장소에 있는 자기 포켓몬(포켓몬 포텐셜의 「자신」 관점, 사용자 결정). `TrainerTriggers.TrainerClause`가 「아군의/이/을」 「자진의 포켓몬」을 「자신」으로, 「아군을 필드에 내보냈을 때」를 「장소에 나올 때」로 바꾼다. 모든 모듈 사건(등장·교대·타이밍·피격·명중·쓰러뜨림·기술 사용·상태·체력·랭크·날씨 등)이 같은 관점으로 트레이너에게도 전달된다(`TriggerModules.Observe` → `TrainerTriggers.Raise`). 그래서 상대 선발 등장도 트레이너 「상대가 장소에 나왔을 때」에 걸린다(문서의 선발 포함 규칙).
