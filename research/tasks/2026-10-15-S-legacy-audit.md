# 지시서 S: 옛 구조 가정이 남은 코드 전수 점검 · 큰 버그 수정

브랜치 `task/S-legacy-audit` · 출력 `outputs/candidate-S` · 먼저 `AGENTS.md`, `PROJECT_HANDOFF.md`(목차)와 `docs/handoff/*.md`의 「사용자 결정」·최근 변경 기록을 읽는다.

## 배경 (사용자 요청: 「옛날 코드 쓰면서 큰 버그 생기는 게 많다. 쭉 확인하고 수정」)
최근 구조가 크게 바뀌었는데 예전 가정을 그대로 쓰는 코드가 실제 버그를 냈다:
- 기술 4개 가정 → 기술 5개 이상 선봉에서 배틀 시작 예외(`RefreshView`, 4d56be8에서 수정).
- 업데이트: 단일 EXE(16MB) 가정의 100KB 크기 검사 → 정상 EXE 거부(e590fdc에서 수정).
- 대기석: 로그 문자열 「『이름』 + 트리거」 매칭으로 교대 판단 → 다른 포켓몬·지난 T 트리거가 섞임, 교대 효과 종류 미구분(b4048a9에서 수정).
- 첫 행동 판정이 교대해 들어온 포켓몬에서 항상 실패(7e429a2에서 수정).

## 할 일
1. **점검 (먼저, 코드 변경 없이)** — 아래 「바뀐 구조」마다 예전 가정을 쓰는 코드를 grep·코드 읽기로 찾는다. 결과를 `research/LEGACY_AUDIT.md` 표로: 위치(파일:줄) · 예전 가정 · 지금 구조 · 증상(재현 가능하면 재현 방법) · 심각도(예외/잘못된 동작/표시만).
   - 기술 목록 4개 고정(배열 길이 4, `Moves[3]`, `Take(4)`, 버튼 인덱스) — 이제 4개 초과 가능(쪽 넘김).
   - 팀 = 트레이너 1 + 포켓몬 ≤6 고정(인덱스 0~5, `members[i]` 대응, 파티 후보 vs 출전 구성 혼동, `initialTeamSizes`, 남은 포켓몬 수 표시) — 이제 파티 후보 다수 + 출전 선택(H).
   - 트레이너 쪽 「전용」 슬롯 — 이제 포켓몬 쪽(트레이너 포텐셜로 판정).
   - 로그 문자열로 사건·발동 여부를 판단하는 곳(`log.Contains`, 『이름』 찾기, 「트리거」 글자 매칭) — 이제 `TriggerFact`·포텐셜 큐가 기준.
   - 정규화 전 원문/옛 표준 문장을 직접 비교하는 곳(마침표 유무, 조사, 「…의 우선도를 +N한다」 같은 옛 문장, 특성 차수 파일 이름) — 이제 `Phrases/` 표준 문장(K·N·O·P).
   - 「아군과 교대」 의미 혼동(물러나는 교대 vs 들어오는 교대) — 진입형은 대기석 전용(b4048a9 + 진행 중인 `task/fix-entry-switch-onfield`).
   - 대기석·장소 구분 없이 `OnField` 가정을 쓰는 포텐셜 판정, 빈사 포켓몬 포함 여부.
   - 자질 등급 해석(EX = AA, 「D-」「A+」「AA+」, 괄호 표기)이 공용 함수를 거치지 않는 곳 — 배열 인덱스 −1 위험.
   - 레벨 상한(200·255 가정) — 샘플에 268 있음.
   - 업데이트/배포: `version.txt`·`release/windows`·단일 EXE 가정 잔재.
   - 성별 없음(「없음」) 기본값을 가정하지 않은 곳, 아인종.
   - 그 밖에 찾은 것.
2. **수정**: 심각도 「예외」·「잘못된 동작」 전부를 고친다(동작 변경은 바뀐 구조 기준 — 사용자 결정과 다르면 고치지 말고 표에 「사용자 판단 필요」). 「표시만」은 쉬운 것만.
   - 고칠 때마다 재현 검사(수정 전 실패 → 수정 후 통과). 실제 화면 흐름이 필요한 것은 `BattleStartFlowTests` 방식(`[Category("UI")]`)으로 두 샘플(실프·칼데아)과 함께.
   - 진행 중인 `task/fix-entry-switch-onfield`(대기석·교대 파일)와 겹치는 곳은 그 작업 병합 뒤 rebase해서 처리.
3. **스모크 검사 하나 추가**: 두 샘플로 「모든 트레이너 × 모든 후보 선봉」을 **10T 이상** 자동 진행(무작위 행동, 고정 시드 몇 개)해 예외가 없는지. 선택 창은 자동 응답. 예외가 나면 그 원인을 1·2에 포함.
4. 문서: 고친 것마다 해당 `docs/handoff/<주제>.md`에 한 줄.
