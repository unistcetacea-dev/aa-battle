# 개요·현재 상태 (PROJECT_HANDOFF.md에서 옮김)

## 목표

가상의 창작 포켓몬이 포텐셜을 사용해 싸우는 Windows 배틀 시뮬레이터를 만든다. 좌우 상단에 HeadKasen 폰트의 AA, 하단에 기술 선택, 중앙에 계산 버튼을 둔다. 시스템 문자는 Pokemon BW 폰트를 사용하고 흑백 고전 도트 디자인을 유지한다.

## 현재 상태

- 메인 실행 파일: `outputs/desktop/AABattle.exe`
- 빌드: `desktop/build.ps1` (.NET SDK 8 이상 필요, 대상은 .NET Framework 4.8)
- 회귀 검사: `dotnet test desktop/AABattle.sln` 또는 `desktop/verify.ps1`
- 팀 편집기는 메인 화면의 `팀 편집` 버튼으로 연다.
- 트레이너와 포켓몬을 `.aabdata.json`에 저장한다.
- 포켓몬 화면의 버튼으로 왼쪽 또는 오른쪽 배틀 슬롯에 적용한다.
- 트레이너 화면의 버튼으로 양쪽 트레이너를 적용한다. 적용 전에는 지령이 없으며, 적용된 트레이너의 활성화된 `지령` 슬롯만 배틀 선언 목록에 표시한다.
- 기술 행동에는 4식 1개와 지령 1개를 선택적으로 선언할 수 있다. 각각 원칙적으로 `1/시`(1시합 1회)이며 사용하지 않고 행동을 확정해도 된다. 사용 이력은 시합 동안 유지되고, 다른 포텐셜에 의한 보충은 향후 포텐셜 실행기에서 처리한다.
- 『돌아와!』는 교대 대상과 함께 선언한다. 기존 포켓몬은 턴 초반에 볼로 들어가 상대의 대상 지정 행동을 피하고, 새 포켓몬은 턴 마지막 교대 시점에 등장한다. 통상교대는 행동 전에 처리한다.
- 기본 4식·숙달/전개 6령과 선택 규칙인 『맞춰라!』·저격/회피 지령을 실행한다.
- 팀 편집기의 능력치 입력은 종족값이다. 슬롯 변환 시 IV 31, EV 0, 성격 무보정이다.
- 타입이나 기술이 참조 데이터에 없으면 제외하며, 유효 항목이 하나도 없으면 적용을 중단한다.
- 포텐셜은 이름, 슬롯, 발동 방식, 사용 제한, 트리거, 효과, 원문으로 분리해 저장한다.
- 지령 이외의 포텐셜은 배틀 데이터에 전달된다. 구조별 실행기를 붙이는 중이며 현재 트레이너 고유의 주요 사건 감시와 단순 능력 랭크 상승을 실행한다.
- 포켓몬 포텐셜 슬롯은 `역할 → 분류 → 주인 → 이명 → 종족①~④ → 속별 → 유대 → 선 → 회피 → 내성 → 격 → 범용 → 부수 → 특권 → PT①~②` 순서다. 고유·전용·지령은 트레이너 포텐셜이다.
- 데이터 편집기의 `포텐셜 종류`는 선택식이다. 포켓몬에는 위 19종과 `전용`, 트레이너에는 고유·지령만 표시하며 기존 파일의 예전 분류값(트레이너 쪽 옛 `전용` 포함)은 그 행에서 보존한다(2026-10-14 변경: 아래 「포텐셜 편집 창」 절).
- 포켓몬의 `역할` 행은 자유 작명하지 않는다. 오레마스 역할 35개와 아바돈 역할 7개 중 하나를 선택하면 표준 효과가 자동 입력된다.
- 아바돈의 `헌트` 6종은 역할이 아니라 `부수`다. 탐사대원·탐사대장은 프라이멀 헌트를 공유하고, 수렵/보급/구급/추적/조사대원은 각각 와일드/브레이크/레스큐/새비지/리서치 헌트와 연결된다. 역할 선택 시 해당 부수 행을 자동 입력한다. 추가 역할 5종은 통솔 A 이상을 요구한다.
- `범용`은 기합·초근성·전투속행·진지작성·군략·초기합 6종, `선`은 선의 선·대의 선·후의 선·삼종의 신기 4종 중에서 선택하며 효과를 자동 입력한다. 삼종의 신기는 육성 AA 이상 전용이다.
- 포텐셜 편집 표의 `상대 타입` 열은 `회피`·`내성`·`격`에서 활성화된다. 포텐셜 종류 → 상대 타입 → 표준 이름 순서로 선택하며 `targetType`을 저장한다. 발동 방식과 횟수는 내부 데이터로 보존한다.
- `발동 금지` 도트 체크를 켜면 `enabled=false`로 저장하며 배틀 슬롯 변환에서 제외한다. 체크를 끄면 다시 실행 후보가 된다.
- 팀 편집기의 `기술·효과 도감`은 등록된 전체 기술을 검색·상세 확인·4개까지 삽입할 수 있고, 내장 및 현재 프로젝트의 포텐셜 트리거·효과를 검색해 선택한 포텐셜 행에 입력할 수 있다.
- 방호 포텐셜은 기술 무효/반사, 버텨라 계열, 방어·특방 강화, 위력·대미지 완화 효과다. 회피, 대미지 유예, 피격 반격, 『기합』은 제외한다. 포켓몬 포텐셜에서 나온 방호 관통은 트레이너 포텐셜의 방호 효과와 『버텨라!』를 관통하지 못한다.

## 다음 구현 순서

1. (완료 2026-10-12, 안정 데이터 ID) 팀 보관함에 복사된 포켓몬이 원본 포켓몬 수정 내용을 안전하게 따라가도록 안정적인 데이터 ID 참조 방식을 설계한다.
2. 교대 시 해제·유지되는 상태변화를 세부 규칙에 맞게 확장한다.
3. 포텐셜 이벤트 큐를 `배틀 시작 → 등장 → 기술 결정 → 행동 전 → 명중/피격 → 대미지 후 → 빈사 → 교대 → 턴 종료` 순서로 만든다.
4. 방호 포텐셜의 출처와 방호 관통 범위를 효과 단위로 구현한다.
5. 사용자가 제공하는 나머지 표준 포텐셜을 선택 목록과 효과 도감에 추가한다.
