# 사용자 결정 (2026-10-14) — 다음 지시서들에 반영

## 기술
- 바꿔치기·트릭: **둘 다 빈손일 때만 실패**(한쪽만 빈손이면 성공).

## 유대
- 뜨거운 유대 「자신의 모든 종족치에 「++」를 부여한다」: 각 종족치를 **현재 등급의 「++」 값**으로 만든다. 등급표:
  - AAA 170～195(-～+), AAA++ = 199
  - AA 140～165, AA++ = 169
  - A 110～135, A++ = 139
  - B 90～105, B++ = 109
  - C 60～85, C++ = 89
  - D 40～55, D++ = 59
  - E 1～35, E++ = 39
  (예: 속도 98 = B → 109. 체력 포함 여부는 「모든 종족치」이므로 체력 포함.)
- 지령 4식(『물러나！』『피해라！』『돌아와！』『버텨라！』 및 확장 지령)도 **이력 기록 대상**.
- 대기 중인 팀원이 받는 트레이너 포텐셜도 **기록한다**(드문 상황이지만 가능하면).

## 오레마스 전용 유형
- 영격: 「상대의 공격기술을 회피하고, ○○한다」의 ○○은 **효과 칸에서 자유 선택**(빈칸 = 효과 모듈 선택).
- 마검: 「통상교대로 필드에 나온 T의 가장 마지막」 발동 시점을 **새 트리거로 만든다**.
- 버서크: 「자신의 체력을 절반으로」 = **현재 HP 기준**.
- 범프업: **패시브**(상시, 자신의 전 종족치 1랭크 상승). 「지시 −1랭크」 디메리트는 **무시**.
- 스토킹: 『에이스』는 **상대**의 『에이스』(상대 『에이스』가 필드에 나왔을 때).
- 삼점방호: 유지 = **아군과 교대해서 나온 턴의 종료 시까지**. 무시 범위 = 상대의 랭크 상승·강화·상태변화 등으로 인한 위력(대미지) 상승 **전부**.
- 페이스메이커: 「여기다！」(발동 조건)를 무시하고 아군의 『에이스』를 발동시킨다.
- 메가진화·폼 변경: **나중에**(지금 하지 않음).

## 기술 (추가)
- 내던지기·자연의은혜 표 값, 소모 시점(명중 시), 소란 2~5T, 참기(사용 T 포함 2T, 공격 대미지만, 행동 실패도 카운트), 아픔나누기 홀수 내림: **현재 구현 그대로 확정**.

## 실프 인헨스먼츠 샘플
- 육성 「EX」: 데이터에는 EX 그대로 넣고, 엔진은 **AA와 동일하게 취급**한다고만 명시(문서·주석).
- 「추가공격」 ≠ 「추가행동」: 추가행동 = 특정 행동 또는 자유 선택, **추가공격 = 방금 내보낸 공격을 한 번 더 한다**.
- 삼각두의 사냥 「…을 임명할 수 있다」류: **자신의 통솔과 관계없이 특정 역할을 임명할 수 있게 하는 문장**(통솔 A 필요 없음).
- 결벽증(특성)·돌격조끼(소지품): **데이터에 추가**(원문 기준).
- 이리스의 「『전용』을 받았을 때」 = **(트레이너가) 이 포켓몬에게 전용 포텐셜을 발동했을 때**(트레이너 포텐셜이라 「받았을 때」로 표현).
- 「아군과 교대해 필드에 나올 수 있다」 류(『역윤회』『역선회』『스토킹』 등): **대기 중인 포켓몬의 포텐셜도 판정한다**. 특정 트리거가 발동했을 때 대기석에서 장소의 아군과 교대해 나오는 효과이므로, 대기 포켓몬의 이런 포텐셜은 대기 중에도 트리거를 본다.
- 금관 사이즈: 종족 중 가장 크다는 설정으로 체력에 큰 보정 → 보정 받아 150. 구체 수치가 없으므로 **체력 종족치 +50**으로 둔다. 데이터의 로보코 체력은 **100**으로 되돌리고 금관 사이즈(+50)로 150이 되게.
- 무위전변: 슬롯 **PT**(①/② 확인 필요).
- 주령괴의 저주 「「악」 데미지」 등 **타입을 단 대미지는 모두 타입 상성을 받는다**(그래서 타입을 적는 것).
- 무위전변: 슬롯 **PT ①**.

## 칼데아 포텐셜
- 『기합』 「남은 체력이 많을수록 발동하기 어렵다」: **체력 최대일 때 1%, 체력 1일 때 「드물게」와 같은 확률**, 그 사이는 남은 체력 비율에 따라 선형. 남은 체력 비례 확률 문장 전부 같은 방식(최대 → 1%, 1 → 원래 표기 확률).
- 「상대의 공격 이외의 대미지를 무시한다」(초근성 등) = **자신이 받는 공격 이외 대미지 무시**(매직가드식).
- 새 상태 정의는 문서에 있다: 번개구름 = 오레마스_기술 「「방어」관통. 상대를 「번개구름」상태로 한다. (*「미래예지」의 유형.)」(예약 공격), 아이스번 = 오레마스_기술 설치기술 「필드에 나온 T, 상대의 기술의 우선도를 -1한다. 「불꽃」「얼음」타입이 필드에 나오면 해제된다.」, 도우미 = 엔진에 이미 있는 상태(`StateEffects` 「도우미」).
- 「기술폭」 = 자신의 기술 개수. 지금은 **장식(효과 없음)**으로 둔다.
- 「필드가 「바다」에 접하고 있을 때」 = **항상 성립(패시브)**.
- 「야생일 때」 = **자신의 역할이 『야생 포켓몬』 또는 『야생의 두목』일 때**.
- 천부의 재능·역할 임명·자질 변화: 역할 임명 = 배틀 중 그 포켓몬의 역할이 바뀌는 사건(통솔과 관계없이 임명 가능 문장 포함), 자질 변화 = 배틀 동안 트레이너 자질 랭크를 바꾸는 효과. **이 방향으로 구현**.
- 전투속행(대미지 지연): 범용 포텐셜이라 **구현해야 한다**.

## 데이터·트리거 정리
- 기술 「분노의주먹」 두 개 중 격투/150/분노 해제 쪽(오레마스)을 **「분노의주먹(오레마스)」**로 이름 변경(기술 데이터·기술 도감 모두). 고스트/50 쪽은 실기 이름 유지.
- 확정 목록 트리거 문장(최종):
  - **삭제**(목록에서 제거): 「장소에 나온 뒤 1T째일 때」, 「직전에 장소에 있던 아군과 교대했을 때」, 「상대의 공격을 방호로 무효화했을 때」, 「상대의 데이터를 완전히 해석했을 때」, 「조건 A 그리고 조건 B」, 「조건 A 또는 조건 B」(두 줄 AND·「또는」 모듈로 대신).
  - **구현**: 「상대의 「속도」 종족치가 「B」 이하일 때」 → 종족치 등급 비교 상태 트리거(능력·등급·이상/이하 빈칸).
  - 「자신이 나무열매를 소모했을 때」·「자신의 소지품을 빼앗겼을 때」: 소지품 처리 사건에 연결해 실제 트리거로(이미 되면 확인만).
- 상태 편집 창에 **얼음의벽** 칸 추가.
