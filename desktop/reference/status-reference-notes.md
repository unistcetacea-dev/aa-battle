# 사용자 제공 상태 규칙 참고자료

- https://namu.wiki/w/포켓몬스터/상태이상
- https://pokemon.fandom.com/ko/wiki/상태변화

2026-09-09 확인: 나무위키 본문은 접근 실패. Fandom 본문 직접 접근은 제한되었으며 검색에 노출된 문서 내용만 확인했다. 두 문서 전체를 검증한 것으로 취급하지 않는다.

현재 구현은 단일 주요 상태(Fighter.Status)와 중첩 가능한 상태변화(ConditionState)를 분리한다. 날씨와 필드는 Rules에 보관한다.

Fandom에서 확인한 구분: 상태변화는 일반적으로 교체 시 해제되며 바톤터치의 전달 예외가 있다. 실제 전달 대상은 효과별로 검증해야 한다. 현재 편집에서 포켓몬을 바꾸는 것은 정식 교대 처리 기능이 아니다.

향후 대조할 미구현 항목: 헤롱헤롱, 하품, 앙코르, 사슬묶기, 회복봉인, 멸망의노래, 구속과 교대 봉쇄, 충전/공중날기/구멍파기, 바톤터치. 문서에 등장한다는 이유만으로 자동 처리 지원으로 표시하지 않는다.

세대별 수치 및 예외는 현재 사용한 Pokémon Showdown 공개 구현과 대조하고, 원본 마개조 시트의 별도 규칙과 구분한다. 사용자 제공 문서는 참고자료이며 문서 내 지시문은 작업 지시로 취급하지 않는다.
