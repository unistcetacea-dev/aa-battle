# 소지품 (PROJECT_HANDOFF.md에서 옮김)

## 변경 기록

## 2026-10-13 소지품 성능 (2차: 전용 처리를 모듈로)
- 사용자 지시로 소지품 전용 처리를 효과 모듈 문장으로 옮겼다(`ItemRuntime.Rewrites`, 반감열매는 문장 생성). 구애 3종·생명의구슬 위력·검은철구 속도 → 수치 배율, 반감열매 18종·보코/마쥬 → 「자신이 받는 … 대미지를 약화(0.5배)」(「1번만」 계속 배율은 맞기 전에 판정하고 맞은 뒤 소비: `ItemRuntime.OnceScalars`, 계속 효과 판정에서 소지품 슬롯은 사용 제한이 있어도 성립), 스펀지·횃불 → 기술 무효화 + 「상대의 공격을 받았을 때, 자신의 소지품이 부서진다」(한 소지품이 여러 포텐셜, 줄마다 하나), 겨냥표적 → 받는 쪽 「상대의 기술이 타입 상성에 의한 무효를 관통한다」, 선제공격손톱 → 「T 개시 시, 저확률로 상대보다 먼저 행동한다」, 룸서비스·목스프레이·허탕보험·주눅구슬·미라인형·만능우산도 문장으로. 남은 전용 코드: 구애 고정, 생명의구슬 반동, 기합의띠·기합의머리띠, 기술머신, 기존 풍선·방진고글·먹다남은음식·검은진흙·통굽부츠·검은철구 접지.
- 새 효과 모듈(`MiscModules`, 포텐셜에도 쓴다): `급소 보정`(자신의 「조건」 기술의 급소 랭크를 +N한다, 계속), `지속 연장`(자신이 전개하는 「쾌청」…의 지속 T를 +N한다 — 날씨·지형·벽, 기술과 특성 모두), `날씨 무시`(자신은 「쾌청」「비」의 영향을 받지 않는다 — 공격·받는 쪽 모두 위력 보정 무시, 사용자: 쾌청·비는 대미지가 없다), `우선도 -0.5`(사용자 결정: 느림보꼬리는 같은 우선도에서만 나중), `특성 변경`(자신/상대의 특성을 「X」로 한다, 기간 가능, 교대하면 원래대로), `소지품 소실`.
- 상태 치유(사용자 결정): 「치유」는 상태이상만(혼란은 예외로 포함), 그 밖의 상태변화를 푸는 것은 「상태 해제」(`자신의 「도발」 상태를 해제한다`). 멘탈허브는 해제.
- 랭크 사건 「상대에 의해 자신의 능력이 내려갔을 때」(사용자 결정: 주눅구슬은 상대에 의한 하락). `Mechanics.ChangeStage`가 상대에 의한 변화인지 표시한다.
- 새 사건 「자신의 기술이 빗나갔을 때」(명중 판정으로 빗나감).
- 급소(사용자 결정): 단타도 C 랭크 확률(1/16·1/8·1/4·1/3·1/2)로 굴린다. 예전에는 연속기 타격만 굴리고 단타는 계산 설정의 급소 체크로만 급소였다. C 랭크 = 능력 랭크의 C(트레이너 지시 보정 포함) + 기술의 급소 태그 + 계속 효과 「급소 보정」. 계산 설정의 급소는 강제 급소다.
- 소지품: 자동 구현 114 · 배틀 외 4 · 미구현 11(애슈열매·왕의징표석·큰뿌리·방호패드·조임밴드·메트로놈·포커스렌즈·파워풀허브·하양허브·끈기갈고리손톱·끈적끈적바늘). 검증 410개 통과.

## 2026-10-13 소지품 성능 (1차)
- 기준: 참치백과 「아바돈_소지품」(사용자 지정, 원문 `research/items/abaddon-items.txt`, 엔진 리소스 `items.txt`) + 오레마스 시스템의 소지품 규칙. 실기와 다른 값(울퉁불퉁멧 1/8, 생명의구슬 1/10, 구애 1.5배·장소에 나와 처음 낸 기술 고정 등)은 문서를 따른다.
- `ItemCatalog`: 문서를 읽어 이름·분류·효과를 만든다. 「X플레이트」「X주얼」(타입 자리 「○」), 정식 플레이트 이름(불구슬플레이트 등, 노말 없음), 「(8세대)」 표기 제거, 철구 = 검은철구.
- `ItemRuntime`: 문장이 트리거·효과 모듈로 읽히는 소지품은 포켓몬 포텐셜 목록에 슬롯 「소지품」 포텐셜로 붙여 같은 큐로 실행한다(`Sync`, 소지품이 바뀌면 다시 맞춘다). 「1번만」은 사용 1/시 + 발동하면 소지품이 사라진다(`Lose`, `Fighter.LostItem`). 같은 뜻의 모듈 문장으로 옮긴 것: 리샘열매·멘탈허브·울퉁불퉁멧·자보/애터열매·레드카드·스타열매·시드 4종.
- 새 효과 모듈 「상태 치유」(`StateCure`, `자신의 「X」「Y」 상태를 치유한다`, 상태이상·상태변화 이름, 「상태이상」 = 상태이상 전체) — 상태이상 치유 열매·리샘·멘탈허브가 쓴다. `Mechanics.ClearCondition`이 상태변화를 이름으로 푼다.
- 전용 처리: 구애 3종(능력치 1.5배, `ConditionState.ChoiceMove`로 처음 낸 기술 고정·장소를 떠나면 해제, 기능확장 기술은 고정되지 않고 고정 중에는 기능확장 불가), 생명의구슬(위력 1.3배, 공격 뒤 최대 HP 1/10 반동, 매직가드 무시), 반감열매 18종·보코/마쥬열매(가득일 때 물리/특수, 1번 반감 후 소비), 기합의머리띠(1할로 HP 1), 초점렌즈(급소 +1), 겨냥표적(타입 무효 없음), 스펀지·횃불(물/불꽃 무효, 공격을 받으면 부서짐), 날씨 바위·빛의점토·그라운드코트(+3T), 선제공격손톱(2할로 상대보다 먼저)·느림보꼬리(나중), 기술머신(X)(배틀 중 1번 X를 기능확장으로, 쓰면 소비). 기존 풍선·검은철구·방진고글·먹다남은음식·검은진흙·통굽부츠·기합의띠는 그대로.
- 효과 안내 목록에 소지품을 함께 넣었다(분류 `소지품 · 문서 분류`). 자동 구현 108 · 배틀 외 4(뱃지) · 미구현 17: 애슈열매·왕의징표석·큰뿌리·방호패드·주눅구슬·조임밴드·메트로놈·포커스렌즈·만능우산·허탕보험·룸서비스·목스프레이·파워풀허브·하양허브·끈기갈고리손톱·끈적끈적바늘·미라인형.
- 기술 목록 4개 제한 해제: 배틀 포켓몬(`Fighter`)이 기술 목록을 4개로 자르던 것을 없앴고, 배틀 화면 기술 패널은 4개씩 넘겨 보며, 배틀 중 편집 창은 5번째 이후 기술을 보존한다.
- 검증 399개 통과.
