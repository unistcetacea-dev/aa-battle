# 포텐셜 효과 구현 질문 30

수집된 4,151개 포텐셜의 효과 문장 4,762개를 기준으로, 자동 실행기의 동작을 결정해야 하는 공통 구조만 추렸다. 트리거가 성립했다는 전제에서 **효과를 언제, 누구에게, 어느 계산 단계에 적용할지**를 묻는다. 같은 답을 공유할 수 있는 중복 문장은 하나로 합쳤다.

답변은 `1. ...`, `2. ...`처럼 번호대로 적으면 된다. 당장 정하기 어려운 항목은 `task`라고 답하면 별도 과제로 남긴다.

## 발동과 대상

1. 한 포텐셜 문장에 효과가 둘 이상 있을 때(예: `소지품을 파괴해 위력을 1.5배로 한다`) 앞 효과가 실패하면 뒤 효과도 실패하는가? `~하고`, `~해`, `~하여`, `그 후` 같은 연결 표현마다 규칙을 다르게 둘 필요가 있는가?

2. `~할 수 있다`는 효과는 트리거가 성립할 때마다 사용자에게 실행 여부를 묻는가? 묻는 시점은 상대의 선택을 공개하기 전/후, 대미지 계산 전/후 중 언제인가?

3. 대상이 `자신`, `상대`, `아군`으로만 적혀 있을 때 각각 현재 필드의 포켓몬만 가리키는가? 대기 멤버나 빈사 멤버까지 포함하는 효과는 반드시 원문에 별도 표기가 있어야 하는가?

4. `아군 1체`, `임의의 아군`, `아군 전체`의 범위를 어떻게 나눌까? 사용자가 고르는 효과와 자동으로 무작위 선택하는 효과의 표준 표현도 정해야 한다.

5. 양쪽에서 같은 시점에 효과가 발동하면 어떤 순서로 처리할까? 포켓몬 속도순, 트레이너 지시 순서, 발동한 사건의 주체 우선 중 무엇을 기본으로 하고 동속이면 무작위로 할까?

## 확률·횟수·연속 처리

6. `저확률/드물게`, `중확률`, `고확률`은 현재 준비된 확률값을 그대로 사용할까? 한 포텐셜이 여러 대상을 건드리면 확률 판정은 포텐셜당 1회인가, 대상마다 각각인가?

7. 연속기에서 `명중할 때`, `대미지를 받았을 때`, `급소에 맞았을 때` 효과는 매 타격마다 실행할까? 효과로 생긴 추가 타격도 같은 포텐셜을 다시 발동시킬 수 있는가?

8. `1/시`, `1/T`, `최초 1회`의 사용 횟수는 언제 소비할까? 발동 선언, 확률 성공, 실제 효과 적용 중 하나를 기준으로 해야 하며, 효과가 무효 또는 실패했을 때 횟수를 돌려주는지도 정해야 한다.

9. 한 번의 사건으로 같은 이름의 포텐셜이 여러 개 감지되거나 복사된 포텐셜과 원본이 함께 있으면 각각 발동하는가? 같은 포텐셜의 중복 발동을 막는 기준을 이름/데이터 ID/슬롯 중 무엇으로 할까?

## 능력 랭크·종족치

10. `임의의 능력을 올린다/내린다`는 발동할 때 사용자가 능력을 고르고, `랜덤한 능력`만 자동 무작위로 정하면 되는가? 명중·회피·급소를 후보에 넣는 범위는 원문에 `전능력` 또는 별도 표기가 있을 때만 확장할까?

11. `가장 높은/낮은 능력`은 종족값, 현재 실능력치, 현재 능력 랭크 중 어느 값을 비교할까? 동률이면 사용자 선택과 무작위 중 어느 쪽인가?

12. 능력 랭크를 `초기화`, `반전`, `복사`, `교환`할 때 명중·회피·급소 랭크도 포함하는가? `능력 변화`와 `능력 강화`를 서로 다른 저장값으로 취급해야 하는 효과가 있는가?

13. 종족치를 다른 능력과 같게 하거나 특정 랭크로 바꾸는 효과가 겹치면 가장 최근 효과로 덮어쓰는가, 원래 종족값을 기준으로 매번 다시 계산하는가? 교대하면 원래 값으로 돌아가는가?

## 배율과 대미지 계산

14. `위력 강화`, `기술의 대미지 강화`, `최종 대미지 강화`를 서로 다른 계산 단계로 분리할까? 원문이 단순히 `강화(1.5배)`라고만 하면 어느 단계에 넣을까?

15. 같은 대상에 강화·약화·완화·반감이 여러 개 겹치면 모두 곱할까? 같은 이름의 포텐셜, 같은 계열의 포텐셜, 서로 다른 출처 사이에서 중첩 제한이 필요한가?

16. `2배가 된다`와 `강화(2배)`를 같은 처리로 볼까? 능력치 2배는 능력 랭크와 별개로 곱하고, 기술 위력 2배는 위력 계산 단계에 넣는 방식이면 되는가?

17. 대미지 계산에서 소수점 버림은 각 배율을 적용할 때마다 하는가, 모든 배율을 곱한 뒤 마지막에 한 번만 하는가? 최소 대미지는 언제 1로 보정할까?

18. `상대 기술의 위력을 반감`과 `받는 대미지를 반감`은 다른 단계로 처리하는가? 급소·방호 관통이 각각 어느 반감/완화 효과를 무시하는지도 문장에 명시된 범위만 따를까?

## 체력·상태

19. 체력 회복 효과는 빈사 포켓몬에게 적용하지 않는 것이 기본인가? `부활/소생`이 명시된 효과만 빈사에서 HP를 되돌릴 수 있게 할까?

20. `체력을 1/N 감소`, `체력을 소비`, `대미지를 받는다`를 서로 구분할까? 소비는 방호·매직가드로 막히지 않고, 필요한 HP가 부족하면 효과 전체가 실패하며, `빈사로 할 수 없다`가 없으면 0 HP가 될 수 있는가?

21. `상대에게 최대 HP의 1/N 대미지` 같은 포텐셜 대미지는 타입·방어·대미지 완화·기합의띠·버텨라·대타 중 무엇의 영향을 받는가? `공격 이외의 대미지`로 분류하면 되는가?

22. 상태이상 부여는 기존 타입·특성·필드 면역을 그대로 적용하고, 이미 다른 상태이상이 있으면 실패하는가? 포텐셜이 `무시하고 부여`한다고 명시할 때만 면역을 관통할까?

23. 혼란·도발·분노처럼 턴 수가 있는 상태변화를 다시 부여하면 남은 턴을 초기화/연장/유지 중 어떻게 할까? 같은 상태를 다시 부여하지 못했다면 후속 효과와 발동 횟수 소비에도 실패로 반영할까?

## 날씨·장소·교대

24. 포텐셜로 날씨·필드·트릭룸·중력을 전개할 때 기본 지속시간은 기술과 동일하게 둘까? 지속시간이 없는 전개 효과는 사용자가 교대해도 유지되고, 더 강한 날씨와 덮어쓰기 규칙도 기술과 같게 적용할까?

25. 설치물을 포텐셜로 설치할 때도 스텔스록 1개, 압정 3겹, 독압정 2겹 제한을 적용하는가? 이미 최대라 설치가 실패하면 연결된 후속 효과도 실패하는가?

26. `아군과 교대한다/아군을 내보낸다` 효과에서 새 포켓몬 선택은 효과 소유자의 사용자가 하는가? 강제교대는 상대 파티에서 무작위인가, 상대 사용자가 선택하는가? 교대 가능한 생존 멤버가 없으면 단순 실패인가?

27. `유턴 효과`와 `추격 효과`를 기술에 부여할 때 어느 시점에 교대·추격을 처리할까? 유턴 사용자가 상대를 쓰러뜨려도 교대하는지, 추격은 교대 전 포켓몬을 때리고 교대가 취소되는 조건이 있는지도 정해야 한다.

## 방호·행동·기술

28. 방호 관통을 `방어 기술`, `특성`, `소지품`, `포켓몬 포텐셜`, `트레이너 포텐셜`로 분리할까? `상대의 방호를 무시한다`처럼 범위가 생략된 문장은 어디까지 관통하며, 반사는 관통보다 먼저 판정할까?

29. `가장 마지막에 추가행동`을 얻으면 새 기술과 대상을 다시 선택하는가, 직전에 쓴 기술을 반복하는가? 추가행동 중에는 다시 추가행동을 얻을 수 없게 하고, 교대·상태이상·빈사로 행동 불능이 되면 소멸시키면 되는가?

30. 기술 타입의 `추가`, `변경`, `유리한 상성으로 계산`을 서로 분리할까? 복수 타입 기술의 자속·상성 계산, `기능확장`으로 생성한 기술의 PP/우선도/접촉·소리 등의 태그, 기술을 반사·복사할 때 공격자와 능력치의 주체를 각각 어떻게 정할지 답이 필요하다.

## 답변 뒤 구현 순서

답변이 확정되면 다음 순서로 구현한다.

1. 공통 효과 큐와 대상 선택: 1~9
2. 랭크·종족치·배율 계산: 10~18
3. 체력·상태 실행: 19~23
4. 날씨·교대·방호·추가행동·기술 변환: 24~30
