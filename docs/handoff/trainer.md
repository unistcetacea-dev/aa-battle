## 2026-09-16 추적대원 교대 제한 템플릿

- 여기서 통상교대는 행동 대신 선택하는 일반 교대와 『돌아와！』를 뜻한다. 따라서 일반 교대·『돌아와！』·강제교대는 허용하고, 유턴 계열과 포텐셜에 의한 교대만 추적대원이 장소에 있는 동안 제한한다.
- 효과 입력기는 `교대 제한 → 상대 → 통상교대 외 수단 제한`을 제공하며, `SwitchEffectRuntime.CanSwitch`가 모든 자동 교대 요청의 사유를 판정한다. 관련 회귀 검사는 `SwitchRuntimeTests`와 편집기 템플릿 복원 검사에 있다.

## 2026-09-16 조사대원 등장·선택 해석
- `조사대원`을 `자신(상대)이 장소에 나왔을 때` 구조로 저장해 자신의 등장과 상대의 등장 모두에서 발동하도록 연결했다. 편집기의 주체 선택에는 `자신(상대)`을 추가하고, 저장 시 두 등장 트리거로 정규화한다.
- 효과 구조에 `데이터 해석 → 상대 → 해석할 수 있다`를 추가했다. 실제 등장 이벤트에서는 선택 발동 질문창을 띄우며, 수락하면 기존 상대 데이터 해석 화면을 열고 해당 상대는 중복 해석하지 않는다.
- 배틀 시작·통상교대·『돌아와！』·포텐셜 교대·죽어내밀기의 등장 경로와 구조 편집기 복원에 회귀 검사를 추가했다.

## 2026-09-16 야생 역할과 능력 상승·강화 무시

  (예: 속도 98 = B → 109. 체력 포함 여부는 「모든 종족치」이므로 체력 포함.)
- 지령 4식(『물러나！』『피해라！』『돌아와！』『버텨라！』 및 확장 지령)도 **이력 기록 대상**.
- 대기 중인 팀원이 받는 트레이너 포텐셜도 **기록한다**(드문 상황이지만 가능하면).

## 2026-10-15 자질 등급 공용 함수(지시서 S)
- 자질 등급(「D-」「A+」「EX」)을 비교·올리내리는 곳은 `TrainerAccessRules.Band`를 거친다(EX = AA). 트리거 「트레이너 자질」(`TriggerStructures.RankBand`)과 자질 랭크 변화(`RoleModules`)가 글자 비교·EX 미처리로 EX 트레이너(마히토 육성, 유키나리 능력)에서 어긋나던 것을 고쳤다. 검사: `LegacyAuditTests`.
